# OBS・TikTokへの接続とPCの目安

更新日: 2026-10-01。対象は現在のAnime2.5DRig方式です。PSDのパーツをブラウザで変形します。GPUで毎フレーム画像を生成するTHA3方式とは必要な負荷が違います。

## 最新の一式

- PSD: `avatars/base-speaking-v2.psd`。21レイヤー、SHA256 `a95f7d47883ce1f6071e470e2b440c2067dba57324f8bb57d8f64a58f9e0d84f`。
- 設定: `avatars/base-speaking-v2.rig.json`。このPSDと組で読み込む。
- 動作: `patches/motion-v2.json` と `patches/face-tracking-v5.json`。セットアップが両方を固定版へ適用する。
- ファイル名のv2は素材の版。最新の首・衣装・髪・眉・うなずきは動作コードの修正で、PSDの絵は再生成していない。

旧セットアップ済みフォルダへ上書きするより、最新版のリポジトリZIPを新しいフォルダへ展開してセットアップする。別の編集があるソースは適用スクリプトが拒否するため、旧フォルダと手動調整JSONは保存して比較する。

## 自宅で接続する

1. READMEのセットアップと起動を実施する。起動したPowerShellは開いたままにする。
2. 普通のChrome / Edgeで `http://127.0.0.1:8000/` を開き、上のPSDとJSONを読み込む。カメラ追従をオンにして、正面で目を自然に開き「正面を記録」を押す。
3. うなずき・眉・片目・口を確認する。OBS表示へ同期する設定をオンにする。
4. OBSの「ブラウザ」ソースへ `http://127.0.0.1:8000/?obs=1` を設定する。幅・高さは1280×1280、まず30fpsで試す。普通のブラウザで開いたPSD・設定・顔追跡値をローカル中継がOBSへ渡す。
5. OBSで背景・他の映像を配置し、仮想カメラを開始する。TikTok LIVE StudioのカメラソースでOBS Virtual Cameraが選択できるか、配信前のプレビューで確認する。
6. マイクはTikTok LIVE Studio側でも選択する。アバターのマイク口パクは、配信への音声送出とは別の機能。

GitHub PagesのプレビューURLをOBSへ貼るだけでは、別プロセスのOBSへモデルと顔追跡が中継されない。自宅では上記のローカル専用サーバーを使う。仮想カメラはOBSで合成した映像として取り込む。OBS内の透過ブラウザソースと、仮想カメラでの透過合成は分けて考える。

### GitHub PagesのURLでサンプルが出る場合

旧版のOBS用URLは `?obs=1` だけだったため、同期モデルがない公開ページでは公式サンプルを読み込んでいた。改良版はプロジェクトの女性アバターを既定にし、公開ページのコピーURLへPSDと設定の指定を含める。

表示だけを試すURL: [女性アバターのOBS用表示](https://naochan3.github.io/vtuber-dev/?obs=1&model=avatars/base-speaking-v2.psd&settings=avatars/base-speaking-v2.rig.json)。OBSのブラウザソースへ貼り、必要ならソースを更新する。

**これは公開素材の表示用。普通のブラウザのカメラ入力をOBSへ送るURLではない。** カメラ連動はローカル専用サーバーを起動し、通常ブラウザとOBSを同じ `127.0.0.1` へ接続する。ローカルのセットアップもPSDと設定をビューア内へ配置する。旧セットアップからの更新は新規フォルダで行う。

TikTok側の選択項目・利用可否はアカウントとバージョンで実機確認する。仮想カメラが選べない場合はOBSのプロジェクター画面をウィンドウソースで取り込めるか確認する。このプロジェクトではOBS・TikTok LIVE Studioをインストールしておらず、実アプリでの表示・音声・配信は未検証。

公式資料: [OBSブラウザソース](https://obsproject.com/kb/browser-source)、[OBS仮想カメラ](https://obsproject.com/kb/virtual-camera-guide)、[TikTok LIVE Studioの仮想カメラ案内](https://www.tiktok.com/live/studio/help/article/Gaming-Co-host/Gaming-Co-host)。TikTok資料は検索結果の公式説明を確認、ページ本文の取得はできなかった。

## PCの目安

以下は購入を勧めるための最低要件ではなく、最初に試す構成の推定。実カメラ・OBS・TikTokを同時に動かしたベンチマークは未測定。

| 用途 | まず試す構成の目安 | 確度 |
|---|---|---|
| アバターとカメラだけ | 現行Chrome / Edge、WebGL対応、Core i5 / Ryzen 5クラス、RAM 8GB以上。内蔵GPUでも候補 | 推定。世代・解像度で差が大きい |
| OBS＋TikTokも同時 | 近年のCore i5 / Ryzen 5、RAM 16GB以上、利用可能ならGPUの動画エンコーダー。30fpsから開始 | 推定。ゲーム同時実行なら別途余裕が必要 |
| THA3で画像生成 | 別環境と対応GPU・モデルが必要 | 現在の方式の最低要件として扱わない |

RTX 4070を持っているなら、今回のブラウザ方式のためにGPUを買い替える必要はないと考える。ただしCPU・RAM・併用アプリが未確認なので、配信中のFPSは保証しない。RAM 16GBを目安とし、多数のアプリやゲームを併用するなら32GBも検討する。

[OBS公式のシステム要件](https://obsproject.com/kb/system-requirements)はWindows 10/11とDirectX 10.1対応GPUを挙げる一方、それだけで配信性能を保証していない。まずOBSの自動構成ウィザードと、配信しない10分間のプレビューで、CPU/GPU/RAM使用量・落ちたフレーム・追跡の遅れを記録する。

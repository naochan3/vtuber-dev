# カメラなしの動作確認

## 改良版をすぐ試す

1. [改良版プレビュー](https://naochan3.github.io/vtuber-dev/?preview=2) を開く。キャラと設定を自動で読み込みます。
2. 「ランダム口パク」で話しているような動き、「角度 X / Z」で肩・胴体と首の追従を確認できます。
3. カメラで試すときは「カメラ追従」を押して許可し、正面を向いて「正面を記録」を押します。新しいサイトなので、公式デモとは別の許可です。
4. 実際の声にも合わせる場合は「マイク口パク」を有効にします。テスト時は「ランダム口パク」をオフにすると、発声との同期を判別できます。

追従改良版は、頭感度1.6・なめらかさ0.65・左右のまばたき連動オフが標準です。顔の描画量も左右は約1.9倍、上下は約1.6倍、傾きは2倍に広げています。呼吸の肩・頭の上下動を強め、同じ周期の横揺れと少し遅れた頭の追従を加えています。呼吸は自動演出で、本人の呼吸の測定ではありません。カメラ・マイクの自動起動はしません。

ウィンクを試すときは「カメラ・マイク」の「左右のまばたきを連動」がオフであることを確認し、片目だけ閉じます。カメラなしなら「ウィンク左」「ウィンク右」で見た目を確認できます。古いブラウザの標準設定にも一度だけ移行を行い、その後のユーザー調整は保持します。

最初の表示はカメラ・マイクなしの自動デモです。録画サンプルも実際の顔・音声を使っていません。描画と顔追跡はブラウザ内で行い、会社PCへのソフトのインストールは不要です。

読み込むファイルは `avatars/base-speaking-v2.psd` と同名の `.rig.json` です。口の感度は初期値1.4、口の「閉じやすさ」は0.3です。以前のブラウザ設定が残っている場合は口の感度を確認してください。

元の公式デモに改良PSDを読み込むと口差分は使えますが、肩・首の追従コードの調整は反映されません。自宅では最新版の `setup-anime25d.ps1` を実行してから起動してください。

## 初版をブラウザで操作する

1. [Anime2.5DRig公式デモ](https://852wa.github.io/Anime2.5DRig/) を開く。
2. 「PSDを開く」で `avatars/base-rig.psd` を選ぶ。
3. 「保存・設定」の「設定JSONを読み込む」で `avatars/base-rig.rig.json` を選ぶ。
4. 「再生」で自動動作を確認する。表情ボタンや顔の向きスライダーでも確認できる。
5. 終了するときは「一時停止」を押すかタブを閉じる。

カメラ・マイクの許可は、このサンプル確認では必要ありません。表示用の描画はブラウザで動くため負荷はゼロではありません。会社PCへの依存関係のインストールや設定変更は不要です。

## 現状の限界

- 改良版の開き口は専用素材、閉じ口は元絵です。閉じ目は公式デモの汎用差分です。
- 口は開閉と変形による表現です。「あ・い・う・え・お」別の差分はありません。
- 首全体を手前に置くと襟を覆うため、襟の金色の縁に沿って衣装を前後のマスクへ分け、背面の襟→首→前面の襟→顔の順で描画します。首を水平に切らず、襟の内側へ入れる方式です。衣装の位置は変更していません。首の上側と下側の追従も分けています。実際のカメラの強い上下動は追加確認が必要です。
- 大きい顔回転・自宅カメラ追従・配信連携・長時間安定性は未検証。
- 動画はVP9 WebM、1280×1280。最新の追従・呼吸改良後は146フレーム・最終時刻4.931秒です。各旧版の記録は検証記録に保持しています。録画設定やフレーム数は自宅PCの性能の測定値ではありません。

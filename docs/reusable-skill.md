# 画像からVTuberを作るスキル

2026-10-01に、これまでの調整を `build-vtuber-avatar` スキルへまとめました。
配布本体は [skills/build-vtuber-avatar](../skills/build-vtuber-avatar/)、入口は [SKILL.md](../skills/build-vtuber-avatar/SKILL.md) です。

## 呼び出し

このフォルダを個人のCodexスキル保存先 `~/.codex/skills/build-vtuber-avatar/` にコピーし、画像と一緒に次のように依頼します。
`CODEX_HOME` を独自に設定している場合は、その `skills/` 配下へ置きます。

```text
$build-vtuber-avatar この画像から、今の改良版の水準を目指すVTuberを作って。
口パク、独立ウィンク、眉、うなずき、髪と上半身の動き、首と衣装の前後を検査し、
OBS用の一式と別PC向け引継ぎを残して。
```

ユーザーは画像と目的を伝えます。座標・modelId・パーツ名の細かな指定はエージェント側で判断します。
スキルを呼ぶだけでGPU利用や素材公開を新しく許可したことにはならないため、既存の許可範囲を引き継ぎます。

**実行先は固定しません。** Colab・準備済みの自宅GPU・別GPUホストから、許可済みで条件を満たす環境を選びます。共通の生成入口 `generate-psd.py` はColabやGoogleアカウントに依存せず、同じPSD・ログ・ハッシュを返します。Colab用ノートは環境準備を含めた一例です。既存PSDからも同じ修正・検査へ進めます。
生成環境のOS・CUDA・モデルの依存関係は確認が必要で、ローカルの実GPU生成や全OS互換性の検証済みを意味しません。

## 自動化した部分

| 段階 | 同梱した処理・ルール |
|---|---|
| 開始 | 新規フォルダ作成、元PNGの保持、ハッシュと未検証状態の記録、既存フォルダの保護 |
| PSD生成 | 実行先を選ぶ共通入口、Colabの実行例、固定版See-through、レイヤー名の正規化 |
| 口 | 必要なときだけ元絵を参照して差分生成、元口の大きさから初期寸法を決め、元画素を照合 |
| 動き | 顔と胴体の追従・遅れ、肩と胸の変形、呼吸演出、左右独立の目、眉とうなずき、毛束別の慣性 |
| 前後関係 | 画像ごとの正規化ポリゴン、対象modelIdの照合、首・襟・腕・背面布の順番 |
| 検査 | 動き・追跡・瞳・髪・マスク・描画順の6種の検査と、正負ポーズの目視確認 |
| 配布 | 最新PSD＋同じPSDの設定JSON＋起動コード＋検証記録＋引継ぎをZIPへまとめる手順 |

画像別の首・襟マスクは、以前の金色判定・固定座標を使い回さず、対象の絵を見て作ります。
共通の動きと画像別の形の修正を分けたので、衣装が変わっても前のキャラの情報を混ぜずに進められます。

## 検証の範囲

スキルの構造、Pythonの静的検査・実入力、公式固定ソースへの差分適用、6種のNode検査を [スキル検査のGitHub Actions](https://github.com/naochan3/vtuber-dev/actions/workflows/skill-validation.yml) で再現できます。
検査には小さな合成PSD・透過PNGを使い、作業一式の作成、既存ファイル保護、別modelIdや範囲外マスクの拒否、名前変更と口追加時の元画素保存を確認します。

**新しいキャラ画像からGPU分解→修正→完成まで通した実績は、まだありません。** 既存一例の改良を汎用化した初版です。
任意の画像で無調整の品質や、すべての崩れの防止を保証していません。完成前に画像ごとの動作確認と修正を必ず行います。
肩・胸・呼吸の動きは演出で、本人の肩や呼吸を測る機能ではありません。音素別の口形、実カメラ・OBS・TikTokは別項目として確認します。

## 引継ぎ・改善する順番

1. `SKILL.md`、参照資料、テンプレートREADMEを読んでから新規フォルダを作る。
2. 新しい透過立ち絵を1枚使い、許可済みGPU環境で実際に一巡させる。
3. `evidence/validation.md` と `evidence/handoff.md` に、調整した箇所・正負ポーズ・未確認を記録する。
4. 別の髪型・襟・袖でも確認し、共通化できた修正だけをスキルへ戻す。特定キャラの座標は戻さない。

現在のキャラの素材と起動方法は [開発引継ぎ](handoff.md) を使います。スキルは別画像を作るための一式であり、現在のプレビューを置き換えていません。

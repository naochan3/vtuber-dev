# 自宅での検証手順

## 共通

- リポジトリとColab結果ZIPを自宅PCへダウンロードする。
- ZIPは新規フォルダへ展開し、元の画像・PSD・ログを保持する。
- カメラ、マイク、OBS、TikTok LIVE Studioのバージョンを記録する。
- `nvidia-smi` のGPU名・ドライバ・使用VRAMと、WindowsのRAM使用量を記録する。
- まず配信せずプレビューで確認する。公開配信の開始はこの検証に含まない。

## 方式①: Anime2.5DRig

1. READMEのPowerShellスクリプトを自宅で実行する。ローカル専用サーバーは停止するまでPowerShellを開いたままにする。
2. `http://127.0.0.1:8000/` で `avatars/base-speaking-v2.psd` と `avatars/base-speaking-v2.rig.json` を読み込む。顔・髪・左右の目・眉・開き口と閉じ口の割り当てを確認し、必要な調整後に設定JSONを日時付きの別ファイルへ保存する。初版との比較には `base-rig.psd` と同名のJSONを使う。See-throughの元PSDは左右の名前が互換でないため、修正版を使う。
3. 最初は操作スライダーで左右向き・上下向き・両目・片目・開口を確認する。破綻した箇所はスクリーンショットで記録する。
4. 自宅のカメラ・マイクを有効にし、正面を記録して、小さな左右・上下・首の傾き、まばたき・左右別のウィンク・発話を試す。頭感度1.6・なめらかさ0.65・左右のまばたき連動オフを確認する。大きく動かした場合と比較し、反応の遅れ・ジッター・首と襟の境界を録画する。カメラと音声による口の制御の競合も確認する。
5. OBSブラウザソース `http://127.0.0.1:8000/?obs=1` の透過背景・動き・表情を確認する。
6. OBS仮想カメラを開始し、TikTok LIVE Studioのプレビューを確認する。

止めるときはサーバーを実行したPowerShellで `Ctrl+C`。既存ファイアウォール設定やポート公開の変更は不要です。

## 方式②: EasyVtuber / THA3

Windows依存があるため、Colabの成功をWindowsでの成功とみなしません。セットアップは [固定版README](https://github.com/yuyuyzl/EasyVtuber/blob/f7dd2de4df93c878b0171f47346ff66414a863e6/README.md) を使い、Anime2.5DRigと別のPython 3.10環境に導入します。

- 公式配布元からTHA3のモデルだけを用意する。THA4・`v4_student`は選ばない。
- `input/tha3.png` をEasyVtuberの `data/images/` にコピーする。512×512、RGBA、透過背景を確認する。
- 起動用GUIは `python launcher2.py`。初回はTHA3の半精度、30FPS上限、補間・超解像なしで比較する。
- USBカメラを使う。追跡が不安定なら、公式READMEに記載されたOpenSeeFace方式を別途比較する。
- Spout2プラグインはOBSのバージョンに合う公式リリースから取得し、自宅でインストールする。OBSのSpout2ソースで透過を確認する。

EasyVtuberの `src/args.py` では、THA3の指定は `--model_version v3`、separableは綴りを含めて `--model_seperable`、半精度は `--model_half` です。READMEの表示名 `v3_seperable` とCLIの引数を混同しないでください。

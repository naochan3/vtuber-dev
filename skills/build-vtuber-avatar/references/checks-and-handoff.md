# 完成前の検査と引継ぎ

## 自動検査

テンプレートREADMEの7種のNode検査と構文検査を実行する。改変したPython補助は利用可能な専用環境でruff・mypy strictと実入力の検査を行う。会社PCに検査ライブラリを追加しない。

- `motion-profile`: 独立した目、感度、時間基準の追従、旧設定移行。
- `torso-motion`: 肩・胸・腰、左右・上下・眉の頂点変化、最大入力時の三角形。
- `eye-hair-motion`: 再開眼時の瞳、毛束の応答差、上下慣性、停止後の収束。
- `face-tracking`: 合成の奥行き、動画縦横比・拡縮・移動・首の傾き、眉とまばたき、旧記録。
- `occlusion`: 元RGBの保持、アルファの再合成、他modelIdへの不適用、解像度、重複、不正値。
- `occlusion-render`: 首を一度だけ描く、毎フレーム首を更新、襟前面・背面布・腕の順番、衣装非表示でも首を残す。
- `obs-startup`: プロジェクトの既定素材・設定、公開用コピーURL、既存中継モデルの優先、設定受信中のモデル切替。

スキルの検査・合成入力の検査・実画像の目視・本人のカメラ・配信アプリを区別する。新画像が通った証拠がない段階で、任意画像への品質保証をしない。

## 目視で確認する

カメラを使わず手動操作で確認できるものを先に済ませる。正負の動きが落ち着いてから画面を保存し、同じ拡大率で比較する。

| 操作 | 確認点 |
|---|---|
| 通常 | 元絵の画風・顔・体形・衣装、顔と首の連続性 |
| 左右向き ±0.6 | 顔と髪の差、頭を少し遅れて追う胴体、破れ・空白 |
| 上下 ±0.65 | うなずき、顔と首・襟の接続、肌の漏れ |
| 傾き ±0.6 | 肩と胸が別に曲がる、腰の一律回転がない |
| 眉 ±0.8 | 眉が見える・髪を突き抜けない、目の開きと混同しない |
| ウィンク左右 | 反対の目は開いたまま |
| 閉眼→開眼 | 瞳が膨らまず輪郭が安定する |
| 口の開閉 | 口位置・大きさ・上下の差分、汎用差分を専用と偽らない |
| 頭を動かして停止 | 根元は固定、毛束の揺れ方に差、過剰な跳ね返りが収束 |
| 腕上下 | 袖・前身頃・背面布の前後が元絵に合う |

大きな入力で崩れる場合は、画像に合う安全な可動域へ狭めるか、該当パーツを補完する。大きく動かすこと自体を品質にしない。修正後は該当ポーズと近い動きを再確認する。

カメラなしで15〜30秒のサンプル動画を保存すると利用者が動きを確認できる。動画の設定30fpsを、実機で測ったFPSとして扱わない。実カメラ映像・顔のランドマーク記録を公開の証跡へ入れない。

## 完成一式

- 元画像・最終PSD・同じPSDの設定JSON・必要な画像別マスク。
- 起動スクリプト・2つの共通差分・回帰検査・上流版とライセンス。
- `evidence/validation.md`: 確認日、入力/PSD/設定ハッシュ、各検査の結果、目視ポーズ、実機未確認、既知の制限。
- `evidence/handoff.md`: 次のエージェントが読むファイル、再生成時のIDとマスク更新、起動手順、次に測る項目。
- `run.json`: 完成状態と、camera_tested / obs_tested を実確認に基づき更新。
- ZIP: 元画像とソースの組を含めて新規作成し、CRC・必須ファイル・ハッシュを照合。モデル重み・認証情報・仮想環境・会社情報・本人映像を除く。

上記記録のファイルがない状態を完成一式と呼ばない。実機へアクセスできない場合は、素材・コード・手動動作確認までの完了として伝える。

## OBSとTikTok

普通のブラウザでモデルと設定を読み込み、そこでカメラとマイクを使う。OBSの `?obs=1` 表示は公式ローカル中継からモデル・状態・追跡値を受け取る。公開のプレビューURLを貼るだけで別プロセスのOBSと同期した扱いにしない。

公開ページのOBS用URLには同梱PSD・JSONの相対パスを含める。指定がなくても `avatars/avatar.psd` を読み込み、公式サンプルへ黙って切り替えない。既存中継にモデルがあるときは中継を優先し、画像指定を理由に上書きしない。設定の取得中にモデルが変わったら前のJSONを適用しない。

OBSの透過ブラウザソースと、仮想カメラの合成済み映像は区別する。TikTok側のカメラ選択とマイクは別途確認する。利用者のアカウントとバージョンで選べるか、配信を始めずプレビューで検査する。

現在の方式はPSD変形なので、GPUによる毎フレーム画像生成の方式とスペックを混同しない。16GB RAM等は試す目安で最低保証ではない。実際に使うPCでCPU/GPU/RAM・FPS・追跡遅れ・10分の安定性を測る。OBSやTikTokの仕様説明は実行時に公式資料で確認する。

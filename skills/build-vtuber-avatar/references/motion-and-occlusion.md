# 動きと前後関係を引き継ぐ

## 共通処理として再利用するもの

| 以前の問題 | 維持する動作 |
|---|---|
| 小さく動いても反応しない・かくつく | 初期頭感度1.6、時間基準の追従。顔・体と目・口の追従速度を分ける |
| 首を傾けると体全体が一律に回る | 腰側を抑え、肩・胸を別々に曲げる。左右向き・傾き・上下を遅れて胴体へ渡す |
| 片目を閉じると両目が閉じる | 左右の開きとフィルターを独立。左右連動は標準オフ |
| 再開眼時に瞳が膨らむ | 自動の再開眼伸縮は除去。明示的な表情プリセットとは分ける |
| 髪が全部同時に跳ねる | 前・横・後ろ、毛束の長さ・根元位置で減衰と慣性を分ける。根元は頭へ、先端は遅れてついてくる |
| 眉と上下向きが弱い | z差による上下向き、正面記録後の眉とまばたきの分離。旧記録は保持 |
| 首が襟から浮く・服の奥へ消える | その衣装の襟前面と背面を分け、背面→首→前面で描く |
| 胸横の背面布が袖より手前 | 前身頃全体を動かさず、対象の布だけを腕・袖の後ろへ分ける |

共通の改良は `patches/motion-v5.json` と `face-tracking-v5.json`。体形依存の胸の揺れは標準0にし、入力と依頼に合う場合だけ調整する。呼吸は演出で、実際の肩・胸・呼吸を測っていない。

カメラON後は正面で自然な目と眉を記録する。新項目は `pitchDepth`, `browStableL/R`。新しい眉基準がない旧記録では従来の計測へ戻る。上下向きの旧基準がない場合も正面記録を取り直すよう伝える。

## 画像別マスクを作る

同梱の `lib/avatar-occlusion.js` は衣装の元画素を、背面・襟前面・腕より後ろの布へ分ける。特定の色を検出せず、画像全体に対する0〜1の座標を使う。ピクセル数やmodelIdを別画像へ流用しない。

1. 元画像とPSDパーツを見て、首が収まる襟の内側の縁と、背面の布が始まる前身頃の縁を特定する。
2. 首が下まで存在するか確認する。肌の画素自体が欠けている場合は描画順だけでは直らない。必要な肌の補完を先に行う。
3. 最終PSDから書き出したJSONの `modelId` を使う。複数の衣装パーツがある場合は単純なtopwear一枚の分割だけで足りるか確認する。
4. `collar_front` に首の手前の襟・前身頃の領域、`rear_cloth` に腕の後ろへ置く布の領域を、閉じた多角形で指定する。必要なければ空配列。
5. `scripts/set_occlusion.py --profile <JSON> --project <作業フォルダ>` で型・範囲・modelIdを照合して保存する。セットアップを再実行してビューア側のデータを更新し、画面を再読み込みする。
6. 静止・左右向き・上下・傾き・腕上下で確認し、首の水平な切断・襟外への肌の漏れ・胸の欠け・袖の補完画素が胸に乗る問題を修正する。

JSONの形式:

```json
{
  "version": 1,
  "model_id": "abc-def-123",
  "layer": "topwear",
  "collar_front": [],
  "rear_cloth": []
}
```

上記IDは形式例。実際には最終PSDのIDを使う。各領域は `[[x1,y1],[x2,y2],[x3,y3],...]` の頂点列で、複数領域なら配列に並べる。xは画像全体の幅、yは高さで割る。頂点数3〜256、領域数32以下。切り出されたレイヤー画像の座標と画像全体の座標を混同しない。

マスクの輪郭はエージェントが画像を見て作る。画像だけから衣装の意味を完全自動判定する機能ではない。描画アルファの分配・再合成はテストするが、輪郭や腕との見た目はポーズで確認する。服の一部が前後に分かれる場合、全体のレイヤー順だけを変える解決へ戻さない。

元の検証キャラの金色の縁検出・中心x=650・y=700〜1118の座標は同梱の汎用処理へ入れていない。大きく横を向いた背面や、画像にない毛束の構造まで復元したと記載しない。

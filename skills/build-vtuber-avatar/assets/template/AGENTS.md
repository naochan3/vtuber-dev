# このアバターの開発

- 入力キャラの画風・属性・衣装を維持する。元画像・PSD・旧設定・失敗ログは保持する。
- 環境の作成・GPU処理・公開は利用者の許可された実行先で行う。重い処理不可のPCへ依存関係やモデルを導入しない。
- 既知の金色の襟、modelId、1280px固定座標を別の絵へ適用しない。画像別マスクを目視確認して作成する。
- スキルの標準はPSDパーツ変形。別モデル方式・3D化・新規課金へ勝手に切り替えない。
- 不足した差分・見えない背面を自動分解だけで復元できたと扱わない。必要な箇所を確認して補完する。
- 動作・カメラ・配信・性能の検証結果を分ける。未確認を成功と記載しない。
- シークレット、モデル重み、会社情報、本人のカメラ映像を公開物へ入れない。
